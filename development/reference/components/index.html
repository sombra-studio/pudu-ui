    UI Components Reference¶

    Quick API reference for built-in interactive components and display elements.

    Button¶

    Bases: Widget

    Bases: Params

    Here you can define parameters for initializing a button.

    Parameters:

    Name Type Description Default
    text str

    The text that will be displayed in the button (optional)

    		 ''
    on_press Callable[[...], None]

    The callback function for when the button is pressed

    		 lambda *args: None
    style ButtonStyle

    The style for the button when unfocused

    		 default_button_style()
    hover_style ButtonStyle

    The style for the button when hovered

    		 dft_btn_hover_style()
    focus_style ButtonStyle

    The style for the button when focused

    		 dft_btn_focus_style()
    press_style ButtonStyle

    The style for the button when pressed

    		 dft_btn_press_style()
